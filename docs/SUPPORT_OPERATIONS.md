## Escalation

1. Support triages issue and records customer/order/document identifiers.
2. If payment, data access or wrong document: escalate as SEV1.
3. If legal/privacy: involve Legal/DPO before response.
4. If engineering defect: create incident ticket and link logs.
5. Close with customer-visible resolution and internal note.

## Response templates required

- Order received / delayed.
- Payment failed / duplicate payment investigation.
- Document generation delayed.
- Document correction request.
- Data subject request received.
- Complaint received.
- Incident status update.

Templates are not approved until legal/support review is complete.
